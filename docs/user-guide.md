# Yuushya Modelling Enhanced Editor 用户指南

## 安装要求

客户端需要以下四项严格匹配：

- Minecraft `26.1.2`
- NeoForge `26.1.2.76`
- Yuushya Modelling `2.4.2`
- Yuushya Modelling Enhanced Editor `0.1.0-alpha`

多人游戏服务端必须安装 Yuushya Modelling，因为方块实体、世界数据和保存协议属于它；增强编辑器只需要装在客户端。Yuushya Townscape 是可选内容 Mod，不能替代 Yuushya Modelling。

## 打开编辑器

1. 在世界中放置 Yuushya Modelling 的实体方块、物品方块或文本方块。
2. 手持“实体方块界面终端”右键目标方块。
3. 增强 Mod 会检查目标界面和数据结构；检查成功时打开增强编辑器，失败时继续打开 Yuushya 原版界面。

增强编辑器不修改打开方式，也不会创建第二套服务端协议。

## 界面布局

- 左侧是图层列表和添加、删除、显隐、撤销、重做操作。
- 中间是三维场景视口。编辑中的模型与直径 25 的球形周边环境使用同一相机，但环境层不可选择、不会进入撤销记录、也不会被保存。
- 右侧是数值检查器、内容编辑、碰撞箱和保存/放弃操作。
- 右上角工具条切换移动、旋转、缩放和关闭。
- 底部状态栏显示当前选择、投影模式、环境加载进度和距离响应线宽。

## 相机与选择

| 操作 | 功能 |
| --- | --- |
| 视口空白处左键拖动 | 环绕视角 |
| 右键拖动 | 平移视角 |
| 滚轮 | 拉近/拉远 |
| 点击模型 | 选择对应图层 |
| `F` | 聚焦当前图层 |
| `1`–`6` | 前、后、左、右、顶、底标准视图 |
| `O` / `P` | 正交 / 透视投影 |

被选中的模型会显示不受遮挡影响的角点标记。Gizmo 会根据模型包围范围向六个方向伸出，大模型不会轻易把手柄完全包在内部。

## 变换工具

| 工具 | 快捷键 | 默认 | `Shift` | `Ctrl` |
| --- | --- | --- | --- | --- |
| 移动 | `W` | `0.1` 格 | `0.05` 格 | `0.001` 格 |
| 旋转 | `E` | `15°` | `5°` | `0.001°` |
| 整体缩放 | `R` | `0.1` | `0.05` | `0.001` |

`Ctrl` 与 `Shift` 同时按下时以 `Ctrl` 为准。吸附基于本次拖动的相对增量，不会先把旧数值强行对齐到网格。

Yuushya 的方块建模界面只公开一个整体缩放控制。本项目因此不提供单轴缩放；缩放操作会向 X/Y/Z 写入同一数值，同时补偿位置以保持可见枢轴稳定。旧数据中已有的非均匀缩放在只编辑其他字段时会被保留。

## 添加和编辑内容

### 方块建模

点击左侧“添加方块”，在选择器中按注册表 ID 或本地化名称搜索。左侧预览会随悬停项更新；点击条目后，新方块在模型原点 `(0, 0, 0)` 创建并自动选中。

### 物品建模

物品选择器支持同样的搜索、悬停预览和原点添加。选中已有物品层后，可从检查器更换物品。

### 文本建模

添加或编辑文本时可输入多行内容，并设置背面剔除和背面镜像。未修改文字内容时，Yuushya 原有样式 JSON 会完整保留。

### 图层操作

- 点击层选择；点击显隐按钮切换渲染状态。
- `Delete` / `Backspace` 或删除按钮移除当前层。
- `Ctrl+Z` / `Ctrl+Y` 撤销或重做；添加、删除、变换、内容编辑和自动 Z-fighting 优化都会进入同一历史记录。
- Yuushya 原有层当前不能重新排序，也不能直接替换已有方块状态；可添加新层或删除原层。

## 碰撞箱

检查器可循环选择：无碰撞、栅栏柱、下半方块、上半方块和完整方块。

Yuushya Modelling 2.4.2 的 `CUSTOM` 仅是空占位，没有可供本界面编辑的自定义 AABB。旧存档中的 `CUSTOM` 可以读取和保留，但不会作为可新建预设出现。需要真正的自定义形状时，请使用 Yuushya 原有建模工具与它支持的流程。

## 自动保存与 Z-fighting

正常关闭、Esc、右上角关闭和“保存并关闭”都会先校验草稿，再通过 Yuushya 原数据包保存。若没有任何变化，不会发送冗余数据包。“放弃更改”是唯一明确不保存的关闭方式。

当两个可见方块存在重叠的共面表面时，保存前会弹出提示：

- “自动优化并保存”：把靠后的冲突层沿冲突面偏移 `0.0000001` 格；
- “仍然保存”：不修改几何数据；
- “返回编辑”：取消本次保存。

仅在边或顶点接触不会被判为冲突。自动偏移很小，但仍属于模型数据修改并且可以撤销。

## 环境预览与性能

编辑器读取模型周围直径 25 的球形区域。半径 9.5 内完整保留，外侧三格使用固定坐标散布形成柔和边缘。周围方块只用于参照，不参与点击和保存。

环境按 16³ 分段采集和编译，区分 opaque、cutout、translucent 渲染层；世界方块更新只使受影响分段失效。如果使用大型资源包，第一次模型/纹理预热仍可能短暂卡顿，之后会复用缓存。

## 常见问题

### 仍然打开原版界面

确认客户端安装的是 Yuushya Modelling `2.4.2`，且日志中没有兼容绑定失败。其他 Yuushya 版本会故意失败关闭增强路径，以避免写坏数据。

### 服务端启动失败

不要在服务端安装增强编辑器。服务端只需要与客户端匹配的 Yuushya Modelling。

### 保存后没有变化

先检查右下角是否显示数值验证或自动保存失败信息。数值必须有限且在支持范围内；缩放必须为正数。网络或服务端拒绝也会阻止成功关闭。

### 线条太粗或太细

线宽会根据 GUI 像素密度和相机距离自动补偿，状态栏会显示倍率。高分屏、窗口缩放和拉远都会改变实际物理像素宽度，这是预期行为。

### 为什么没有单轴缩放或自定义碰撞 AABB

两者都受 Yuushya 2.4.2 的宿主数据契约限制。本项目不创建私有存档字段或额外服务端协议，因此分别使用整体缩放和现有碰撞预设。
